# Mahara BPO logo system

The ribbon M is shared by the English and Arabic identities. Logo lettering is
outlined vector artwork: it does not depend on web fonts being available.

| Asset | Use |
| --- | --- |
| `logo-en-dark.svg`, `logo-ar-dark.svg` | Primary lockups on dark backgrounds |
| `logo-en-light.svg`, `logo-ar-light.svg` | Primary lockups on white or light backgrounds |
| `wordmark-en-dark.svg`, `wordmark-ar-dark.svg` | Standalone names on dark backgrounds |
| `wordmark-en-light.svg`, `wordmark-ar-light.svg` | Standalone names on light backgrounds |
| `mark-dark.svg`, `mark-light.svg` | Standalone symbol |
| `favicon.svg`, `favicon-32.png` | Browser icons |
| `apple-touch-icon.png` | 180px home-screen icon |
| `mark.png` | 512px square symbol |
| `logo-preview.png` | Logo image for the existing social and organization metadata |

“Dark” means **for a dark background**, with light lettering and gold #C9A96E.
“Light” means **for a light background**, with charcoal lettering and deeper
gold #8C6F3E. Keep each SVG's aspect ratio and clear space. Use the standalone
symbol below 120px total lockup width. Do not add shadows, gradients, outlines,
or stretch the artwork.

The mark began as an original image-generation design and was reconstructed
as smooth, solid-fill vector paths. The wordmarks use outlined Montserrat and
Cairo lettering. The Arabic company name is مهارة.
